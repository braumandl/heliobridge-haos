# Changelog

## 1.3.0

- Removes fixed local app paths and fixed Supervisor slugs.
- Updates the app from the public HAOS repository through the Supervisor Store API.
- Adds automatic target-app discovery and optional explicit slug override.
- Adds configurable periodic checks, automatic update toggle, and backup-before-update.
- Upstream source mirroring is handled by the repository's scheduled GitHub Actions workflow.
